# Authored methodology-document reference

[The document](document.md), [supporting records](reviews.md) and [identity record](result.md) are authored illustrations for the complete supplied-evidence case. It is not a CLI execution, evaluator result or institutional approval. A real invocation must create its own result record and identities. The reference is a review aid, not permitted evidence for a subject executor or evaluator.

The missing-locality case removes a required numerical result. An honest document can retain the available account and expose the gap, but cannot meet D5 or claim full document fulfillment. The selected institutional-gap requirement is different: it explicitly requires disclosure, so its placeholders can satisfy that disclosure while the facts remain unresolved.
