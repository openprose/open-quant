# Permitted source register

This register binds evidence, not additional execution requirements. Use the shared sources below for either mode. Embedded external links are further-reading locators and do not authorize retrieval or make unread sources available evidence.

| Source | Permitted use and limits |
|---|---|
| [Model brief](brief.md) | Current documentation purpose, selected construction, stipulated method and the scope of supplied versus absent rationale. |
| [Complete numerical packet](../../credit-loss-review/inputs/complete.json) | Selected method inputs, five native probability nodes, four intervals and all six observed constructions. Its case label selects this one packet; do not import other reporting cases. |
| [Calculation source](../../credit-loss-review/model/measure.py) | Exact local implementation, constants, QuantLib calls and Decimal control calculations. Source inspection is permitted; execution is not. |
| [Numerical receipt](../../credit-loss-review/receipt.json) | Earlier source/environment identities, observed process result and reproduction/projection scope. It is not a documentation result or independent institutional validation. |
| [Institutional facts](institutional-facts.md) | Three selected categories and their absence from these inputs. No names, deployment decisions or review records are supplied. |

The documentation may explain mathematical relationships supplied by the brief and code, checking arithmetic against retained observations. It must distinguish those sources from an independently inspected upstream implementation or a fresh calculation. The original credit-loss review's report layout and its alternative cases are not part of this documentation agreement.
