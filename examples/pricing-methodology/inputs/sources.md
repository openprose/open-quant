# Permitted source register

This register binds evidence. Linked source material does not add execution authority or enlarge the reading scope.

| Source | Use and limits |
|---|---|
| [Model brief](../../implementation-review/inputs/brief.md) | Model identity, documented domain, A/B/C mappings, intended bounded use and absent deployment/acceptance/review records. Its implementation-review purpose supplies model context; this program requests a methodology document. |
| Caller-selected numerical packet | For `complete`, read [complete](../../implementation-review/inputs/complete.json). For `baseline-only`, read only [baseline-only](../../implementation-review/inputs/baseline-only.json). Actual retained native/reference observations; an omitted record does not prove that its calculation never ran. |
| [Calculation source](../../implementation-review/model/measure.py) | CASES and VARIANTS, domain checks, native mapping, reference method and recorded controls. Read but do not execute. Source inspection may establish a mapping without establishing a missing numerical observation. |
| [Comparison policy](../../implementation-review/inputs/policy.md) | Selected populations, units, reference usability, price/parity tolerances and their limited meaning. The source-only reporting program and other packets are not adopted. |
| [Numerical receipt](../../implementation-review/receipt.json) | Earlier environment, source identity and packet-projection provenance. Its counts do not supply withheld values or constitute new execution evidence. |

No new institutional records are supplied. The three selected categories are accountable ownership, actual production deployment/acceptance and independent review. Their absence from this public example does not establish that an institution never performed those activities.

External references inside registered material are further-reading locators. This program does not retrieve them or claim to have inspected their contents.
