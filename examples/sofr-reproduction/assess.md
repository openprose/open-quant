# Assess a bounded SOFR reproduction

**For agents.** Execute under the caller's selected OpenProse kernel. The working root is the source repository, two directories above this file.

The caller supplies the actual subject result-directory path and any additional execution evidence. Ask for absent or ambiguous bindings. Account for required report.md, result.md and calculation/ artifacts; missing required artifacts are findings, not permission to select another run. Adopt [assessment](../../contracts/assessment.md) against [the original reproduction program](program.md), its adopted definitions and original source/input/environment selection. Do not execute or repair the subject.

Check the report and result against their requirements. Check the fresh calculation evidence, including the helper's execution.json, comparison.json, log, staged identities and output, against the selected calculation, attempt/deadline limits and original numeric and structural comparison criteria. Inspect retained values and perform comparison arithmetic as needed; a `matches` flag is not a substitute for its supporting evidence. A historical receipt cannot establish that this invocation ran. Matching output from failed, interrupted or unsettled execution does not establish successful reproduction.

Distinguish numerical agreement, comparison completeness, source consistency and evidence of permitted execution. Report conflicting identities, changed criteria, absent records and unavailable original revisions without silently substituting current source. Matching before/after hashes do not prove every intermediate action or exclude an unobserved extra attempt. Preserve supported content findings while leaving unsupported execution effects unresolved.

For each applicable requirement, report met, not met or unresolved with locators. Any supported mandatory violation makes overall subject fulfillment not met; otherwise missing support for a mandatory requirement makes it unresolved; only support for all mandatory requirements makes it met. An accurate failure report does not fulfill the subject's request to reproduce. A decisive negative finding does not by itself complete this assessment: account for content, calculation, comparison, result and execution requirements separately.

Write only assessment.md in a fresh directory under `results/sofr-reproduction-assessments/`, identifying subject/agreement/evidence identities, findings, coverage, overall subject fulfillment, assessment fulfillment, remaining work and the actual path. Preserve source and subject artifacts. Do not run financial code or the reproduction helper, install dependencies, retrieve data, change requirements or create institutional approval. No authored reference or test answer substitutes for the selected evidence.
