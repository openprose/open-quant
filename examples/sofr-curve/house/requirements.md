# Example house requirements

These fictional conventions belong to the example caller. They are not regulatory requirements or a default policy imposed on other organizations.

Write a decision note of at most 700 words, excluding the title and source-locator list. Use these headings: Purpose, Decision and reasons, Evidence and alternatives, Limitations, Institutional information.

Identify methods A and B before using those labels. Display forward-rate differences in basis points, using enough decimal places to distinguish the observed values. Attribute the decision to the supplied developer brief. Include both a benefit and a limitation with their exact results.json field locators and the as-of date.

Start with: “This is a methodology demonstration, not a complete regulatory submission. Institutional facts are supplied by the deploying institution.”

Use `[INSTITUTION-SUPPLIED: description]` for the selected missing facts. Do not describe the document as approved, certified or a completed institutional model review.

An author can add a presentation requirement here, such as a comparison table with separate method, evidence and limitation columns, then invoke the program again. This sentence describes an editing option; it does not adopt that extra table requirement.
