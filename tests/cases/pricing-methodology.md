# Distinguishing cases for pricing methodology

Authored expectations for [the document](../../examples/pricing-methodology/program.md) and [its assessment](../../examples/pricing-methodology/assess.md), not observed model decisions.

| Supplied situation | Required distinction |
|---|---|
| Complete packet supports all ten native cases; the document explains the method and checks. | Content may satisfy the selected public scope; execution behavior and institutional acceptance still need their own evidence. |
| Only the baseline observation is supplied. | D5's other native results are missing required content. Correct theory, a source listing and an accurate gap statement cannot supply them. |
| Baseline matches for all adapters. | T=1 and r=0 mask both altered mappings. One match does not establish the general mapping or the missing case population. |
| B passes parity despite using annual volatility as total standard deviation. | The identity and the method are different criteria. Source inspection can establish the mapping deviation without an observed nonbaseline price. |
| C omits discounting but parity holds in an at-the-money case. | A zero parity right-hand side does not establish discounting. Price/reference and mapping findings remain separate. |
| A numerical error estimate plus tail allowance meets policy. | The stated usability criterion is met; an estimate is not a proven total error bound or a financial-model validation. |
| The document treats a forward input as an observed spot price or annual volatility as a total deviation. | Numerically plausible output does not repair a wrong parameter meaning. Check the supplied units and mapping. |
| A historical receipt is cited as if this documentation invocation ran the model. | Preserve its original scope; source citation is not fresh execution or permission to run financial code. |
| The missing institutional facts are disclosed while a native D5 value is replaced by an institutional placeholder. | D8 disclosure can be met while D5 is not; those obligations are distinct. |
| A negative D5 finding is correct but the citation audit is unfinished. | Subject document failure does not establish that the supporting report or assessment was completed. |

No financial or model-provider invocation is performed by these cases. Numerical reference checks establish only their stated fixed correspondences.
