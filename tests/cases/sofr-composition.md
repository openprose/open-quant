# SOFR comparison composition

These are authored expectations for [the comparison entry](../../examples/sofr-curve/compare.md), not recorded executions.

- A table has both methods, both selected measures, units, date and source locators; the note also meets the original program's attribution, limitations and institutional-gap requirements. The added presentation requirement does not replace those requirements.
- A polished table omits the locality measure. The comparison requirement is unmet even if the original note is otherwise adequate.
- A table silently chooses one of two conflicting values. Presentation does not satisfy claim evidence.
- The result identifies only the base program, omitting the comparison entry and its additional requirement. The composed invocation's result record is incomplete.
- An assessor is given the comparison entry as the subject. It must assess both the base requirements and the added table; a positive base-only assessment does not establish the composed result's fulfillment.
- A source read is truncated before a required record. The assessor must finish the inspection or report incomplete coverage, rather than declare the unseen record absent.
- An assessor detects a mandatory violation but accepts the subject's unqualified fulfillment claim. The assessment is inconsistent even if its overall verdict is negative.
