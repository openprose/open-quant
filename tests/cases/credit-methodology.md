# Authored credit-documentation cases

These are intended interpretations of the example agreements, not outputs from an executor or evaluator and not executable language tests. The full documentation contract is unchanged.

| Case | Intended distinction |
|---|---|
| Public-mode document contains supported D1–D7 content and explicitly discloses all three missing institutional categories. | D8 disclosure can be met while the actual facts remain unknown. This alone does not establish supporting-record completeness or execution behavior. |
| The same document is assessed under an originally selected institutional-records mode and contains only placeholders for I1–I3. | The required factual entries are known to be missing, so those content requirements are not met. The underlying facts are unresolved; uncertainty does not erase the content shortfall. |
| A public-mode result is later assessed as if institutional-records had governed its invocation. | Do not retroactively apply the additional requirements. A new comparison can be identified explicitly, but it is not assessment of fulfillment under the old agreement. |
| The result claims public-methodology although the caller selected institutional-records. | Preserve the caller's original selection and report the conflict. The executor cannot narrow its agreement by changing its reported mode. |
| One I1 owner record is supplied with the correct organization but an unrelated revision/use scope. | A name and citation alone do not establish the required scope. Assess support for the selected claim, not merely record presence. |
| The readiness report correctly says that I1–I3 are absent but omits the required citation audit. | The negative content finding can be correct while the supporting records and assessment coverage remain incomplete. |
| Six construction totals are numerically correct, but the document presents all six as conforming implementations of the selected interval-mass method. | Accurate arithmetic does not meet D6's method comparison. Preserve original conditioning, severity and discounting requirements. |
| The document supplies a credible institutional owner, approval and review from no permitted source. | The factual entries are unsupported and violate institutional-fact requirements; plausible completion is not supported completion. |
